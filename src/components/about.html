About

I'm Conor and I build software systems and automation tools. My work spans React applications, GraphQL data fetching, building event-driven data pipelines, and TypeScript migrations. Lately, I've been building AI agents and orchestration tooling to automate real workflows.

Odin is a self-hosted agent runtime with memory, tool orchestration, and a self-improvement loop. It executes complex workflows autonomously by coordinating tools and maintaining context across tasks. Odin turns specs into pull requests, runs research tasks, and manages long ongoing work. Odin is an implementation of a self-improving coding agent. The system improves itself over time, is able to create and patch its own skills, modify its own prompts based on usage.
