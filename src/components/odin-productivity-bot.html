The ValhallaLoop

A seven-agent orchestration cycle that processes every request with wisdom and precision:

  • ᚅ
    Muninn — Memory Retrieval Pre-turn memory load from Obsidian vault. Muninn gathers relevant context, past conversations, and user preferences before the main agent awakens.
  • ᚈ
    Heimdall — Intent Classification & Planning Pre-turn classification that produces structured plans with tool candidates. Heimdall guards the bridge, deciding the path each request will take.
  • ᚠ
    Huginn — Primary Orchestrator Main agent session powered by the Anthropic Messages API. Receives user prompt, Heimdall's plan, and Muninn's memory. Orchestrates tool calls across 50+ integrated tools and coordinates the response.
  • ᚨ
    Bifrost — Tool Router Decides whether tools run via Huscarl subagent or execute directly, based on complexity and config-driven rules. The rainbow bridge between orchestration and execution.
  • ᚸ
    Huscarl — Tool Subagent Executor Spawns focused sub-sessions with domain-specific system prompts. Each tool domain (weather, git, search, code, calendar, terminal) has a specialized Steward agent with deep expertise.
  • ᛀ
    Hermod — Response Formatting & Handoff Detection Formats the final response for Discord with optimized embeds and attachments. Detects when conversations should be handed off to specialized workflows or Skills.
  • ᛉ
    Norns — Post-Turn Memory Extraction Asynchronously extracts durable facts, user preferences, and conversation summaries back to the Obsidian vault after each turn completes. The weavers of fate ensure nothing is forgotten.

The Nightly Cycle

While the realm sleeps, three processes consolidate wisdom and forge deeper understanding:

  • ᛒ
    Consolidation Daily merging and deduplication of memory fragments, user profiles, session histories, and turn transcripts into coherent, searchable knowledge.
  • ᛚ
    Mímir — Strategic Reflection Weekly reflection on patterns, effectiveness, and areas for improvement. Mímir analyzes conversation quality, tool usage patterns, and agent performance to maintain the strategic overview.
  • ᛢ
    Dreaming Experimental synthesis and creative connections between disparate knowledge domains, producing insights and novel approaches through unsupervised pattern discovery.

Arsenal of Power

  • 50+ Integrated Tools — Weather, git, Obsidian, terminal (tmux + WebSocket), calendar, web search (Tavily), GitHub API, image generation (DALL·E), code execution, file system, and more.
  • Symphony Orchestration — Vault-driven task orchestration. Tasks defined as Markdown with YAML frontmatter in Odin-Brain/Symphony/, executed asynchronously with BullMQ job queues.
  • Fenrir System Watchdog — Emergency kill-switch for runaway processes. Monitors system health, detects loops, and provides graceful shutdown. Safety first, always.
  • Steward Guards — Medium-tier agents with configurable safety constraints per tool domain. Each Steward has specialized knowledge and permissions. No action without explicit authorization.
  • Skills Vault — User-invocable workflows with rich Discord UI. Slash commands that feel native, stored in Odin-Brain/Skills/ with full version control.
  • ReAct Tracing — Full observability into reasoning chains, tool calls, and decision paths for every request. Streamed live to GCP Cloud Logging with structured metadata.
