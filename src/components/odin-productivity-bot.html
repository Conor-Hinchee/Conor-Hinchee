A Claude Code plugin for AI coding work: plan, execute, review, then sign-off, with a human approval gate between each step. A local dashboard shows a live diff with a written rationale. Anything that took more than one pass becomes a proposed fix to the agent’s own rules. Started as a self-hosted agent runtime; now a skill.
