Odin - Productivity Bot

A Discord bot built to help teams stay productive with reminders, task tracking, calendar integration, and knowledge management through Obsidian vault integration.

Key Features:

  • Persistent terminal sessions with tmux for seamless command execution
  • Obsidian vault integration for personal knowledge management and memory
  • Google Calendar integration for event scheduling and reminders
  • Natural language interaction powered by Claude AI

Technical Highlights:

Built with TypeScript and Discord.js, Odin integrates with multiple APIs to provide a comprehensive productivity toolkit. Features include persistent memory through Obsidian markdown notes, calendar event management via Google Calendar API, and interactive terminal sessions for development tasks.
