#### Working on this site

Vite + TypeScript + Tailwind CSS v4. Pages live in `src/` (`index.html`, `blog/`, `now/`) and pull in `src/components/*.html` partials via `<module href>`. Static files in `src/assets/` are served from the site root.

```bash
npm run dev        # dev server on :3000 (PORT=xxxx to change)
npm run build      # typecheck + production build into dist/
npm run preview    # serve dist/ on :3000
npm test           # Playwright against the production build
npm run lint       # prettier + eslint
```
